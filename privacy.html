Privacy Policy – Hestia

Last updated: 8 November 2026

Hestia is a personal assistant that I run for myself on my own computer. It is not offered to the public, and it has one user: me, the person who created it.

What it accesses

With my permission through Google sign-in, Hestia reads and manages my own Google Calendar and Gmail. It uses this to show me my schedule, set reminders, and help sort my email.

How the data is handled

  • The data is processed on my own computer, for my own use.
  • It is not sold, shared with or transferred to anyone else, and it is not used for advertising.
  • Sign-in tokens are stored only on my own computer. Access can be revoked at any time from Google Account → Third-party connections.

Google API Services

Hestia's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
